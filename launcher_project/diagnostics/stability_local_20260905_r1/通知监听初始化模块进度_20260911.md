# 通知监听初始化模块进度（2026-09-11）

当前APK仍为R17；本轮新增两个自有Java模块及测试，尚未生成R18工作树/APK、尚未接入Android桥接，也未关闭此前已确认的授权误判问题。

- InitProcess：使用进程管道可读字节数读取，避免readLine先阻塞再计时；等待采用单调时钟，每次检查Service归属和中断。限制输出量，超时结果不携带可误信的部分输出，返回真实进程退出码；中断恢复标志；finally请求终止进程并关闭各流。Java8编译和66项断言通过，覆盖无输出停滞、超限、Service失效、中断、流/清理异常及真实JVM echo子进程。没有运行ADB或系统设置命令。进程创建和平台流/清理行为仍是外部耗时边界，destroy请求不等于保证OS即时终止，也不撤销已经执行的动作。
- ListenerList：将权威读取成功与未知状态区分；未知时adding返回null阻止列表写回，成功读取null/空串才视为空列表。按组件精确匹配并支持相对类名，保留其他组件和原列表，拒绝畸形、超长、过多表项。Java8编译和47项断言通过。读取成功标记在测试中注入，后续必须由可靠Android读取桥接提供；不能继续把ADB空字符串自动认作成功读取。

源码：launcher_project/stability_modules/src/com/byd/launcher/stability/InitProcess.java、ListenerList.java。JVM证据：diagnostics/stability_local_20260905_r1/modules/init_process_r1和listener_list_r1。源码SHA256和待办清单见notification_init_modules_draft_20260911.json。
